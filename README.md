# Getting Started

You can start exploring the repo locally, or add your programs too in `/contributors` directory. If not exist then do create it.

Here is how to clone and get started fully on your local machine.

```bash
git clone https://github.com/saqibbedar/ai-ml.git
cd ai-ml && code .          # && code . is vs code command, if you don't use that skip && code .
```
